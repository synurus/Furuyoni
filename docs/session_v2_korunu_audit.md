# v2 검수 시트: 코르누 (오리진 11장)

> 스팀판 코르누 카드와 대조. 불일치 시 메모에 올바른 값 기입.

## 핵심 신규 개념: 동결 (룰북 13장)
- **동결 토큰**: 게임 바깥(무한) ↔ 상대 오라 사이만 이동. '동결된다' = 게임 바깥→오라 1개
- **오라 상한 5 = 벚꽃결정 + 동결 토큰의 합**. 동결이 오라 칸을 잠식 (전진/휘감기/오라뎀 받기 제약)
- **오라 꽉 참** = 결정+동결 = 5. 여러 카드가 이 조건 참조 (검의 춤, 눈 타기, 콘루 루얀페, 레타르 레라)
- **품기 변경**: 동결된 플레이어의 품기 = 동결 토큰 1개를 게임 바깥으로 (해동). 결정 이동 없어도 선택 가능
- ⚠️ **보존식 영향**: 동결 토큰은 벚꽃결정(36개)과 별개 계정 → 검증기 확장 필요

### ☐ 눈 칼날 (공격, 통상패) 거리 3-6 1/1 `[재연 패치]`
- 【공격후】상대는 1회 동결된다.
- 📝 재연: 3-6, 공격후 동결

### ☐ 선회날 (공격, 통상패) 거리 2-3 2/2
- 【상시】이 카드에 대응을 했다면 대응을 해결한 뒤에,  /  / 간격⇔더스트:2

### ☐ 검의 춤 (공격, 통상패) 거리 4-5 2/1
- 【상시】상대의 오라가 꽉 차있다면, 이 《공격》은 +1/+1된다.

### ☐ 눈 타기 (행동, 통상패) 
- 간격⇔더스트:1 /  / 상대의 오라가 꽉 차있다면, / 더스트→간격:1 / 을 해도 좋다.

### ☐ 절대영도 (행동/대응, 통상패) 
- 전력화: 공격 『적정거리2-5、1/2』를 수행하고, 상대의 오라의 빈 칸이 없어질 때까지 동결시킨다. /  / 기본행동 《휘감기》를 1회 수행한다. 상대가 3개 이상 동결되었다면 추가로 한번 더 수행한다.

### ☐ 동상 (부여, 통상패) 납 2
- 【전개시】상대를 동결시킨다. / 【전개중】상대는 기본 동작 《품기》를 할 수 없다.

### ☐ 서리 가시덤불 (부여, 통상패) 납 2
- 【전개중】자신의 턴에 자신이 처음으로 하는 비장패가 아닌 《공격》은 +1/+1 된다. / 【전개중】상대가 동결되어있다면 자신의 턴 개시 페이즈에 이 카드에 올려진 벚꽃 결정을 이동시키지 않아도 좋다.

### ☐ 콘루 루얀페 (공격, 비장패) 거리 3-5 2/3 소모 4 `[재연 패치]`
- 【공격후】상대가 오라 데미지를 선택했다면 상대의 오라가 꽉 찰때까지 동결시킨다.
- 📝 재연: 소모4, 적정거리 3-5 (효과 유지)

### ☐ 레타르 레라 (행동/대응, 비장패) 소모 2
- 상대의 오라가 꽉 차있다면 대응한 공격을 무효한다. 그렇지 않다면, / 간격→상대 오라:1

### ☐ 우파스 툼 (공격, 비장패) 거리 3-6 0/- 소모 0
- 【공격후】상대를 동결시킨다. (이 카드는 아직 사용중이기 때문에 오라가 꽉 차도 즉재기되지 않는다) / ---- / 즉재기:상대의 오라가 꽉 찬다.

### ☐ 포루챠르 토 (부여, 비장패) 소모 2 납 1
- 【상시】이 카드를 코스트4로 쓰면 《대응》을 가진 것처럼 상대의 《공격》에 끼어들어서 사용해도 좋다. / 【전개시】간격⇔더스트：1　　상대는 1번 동결한다. / 【파기시】이 카드를 납4로써 사용해도 좋다.（코스트는 지불할 것）

## ⚠️ 특히 확인할 것

2. **우파스 툼**의 즉재기 + '사용중이라 즉재기 안 됨' 상호작용 — 텍스트 정확한지
3. **포루챠르 토**: 코스트4로 대응 사용 / 파기시 납4 재사용 — 복잡, 원문 정확도 확인
