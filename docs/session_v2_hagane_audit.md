# v2 검수 시트: 하가네 (오리진 11장)

> 스팀판 하가네 카드와 대조. 불일치 시 메모에 올바른 값 기입.
> `[재연 패치]` 카드는 패치노트 기반이라 특히 주의.

## 핵심 신규 개념 확인
- **원심**(6-2): 현재 페이즈에 아직 공격을 안 했고 & 간격이 턴 시작보다 2↑ 멀어졌을 때만 사용 가능
- **초극**(10-21): 이 공격의 오라 데미지 상한(=상대 오라 수)이 없어짐 → 오라로 못 받게 만들 수 있음
- **모루**(6-3): 하가네 전용 영역(통상패+결정). ⚠️ 현 데이터/카드에 모루 사용 카드가 있는지 검수 시 확인 필요

### ☐ 원심격 (공격, 통상패) 거리 2-6 5/3 `[재연 패치]`
- 원심 / 종단
- 📝 재연: 2-6 5/3 원심/종단

### ☐ 사풍진 (공격, 통상패) 거리 0-6 1/- `[재연 패치]`
- 【상시】간격이 턴 시작 시와 비교해 2 이상 변화했다면, 상대는 손패를 1장 버림패로 해야 한다.
- 📝 재연: 0-6 1/-

### ☐ 대지 부수기 (공격/전력, 통상패) 거리 0-3 2/-
- 대응불가  /  【공격후】상대의 집중력은 0이 되고, 상대를 위축시킨다。

### ☐ 초반동 (행동, 통상패) 
- 현재 간격에 따라서 아래를 한다. / 5이상…간격→자신 플레어:1 / 4이하...상대 플레어→간격：1

### ☐ 원무련 (행동, 통상패) 
- 원심  / 상대의 플레어가 3 이상이라면、상대 플레어→자신 오라：2

### ☐ 종 울리기 (행동, 통상패)  `[재연 패치]`
- 원심 / 다음 《공격》은 +1/+1 또는 대응불가(통상패)+거리확대(원1) 중 하나를 얻는다.
- 📝 재연: 선택형 버프로 변경

### ☐ 인력장 (부여/대응, 통상패) 납 2 `[재연 패치]`
- 【전개시】간격→자신 오라：1 / 【파기시】자신 오라→간격：1
- 📝 재연: 부여(대응) 납2

### ☐ 대천공 크래시 (공격, 비장패) 거리 0-10 X/Y 소모 4
- 초극  /  【상시】X는 현재 간격이 턴 시작시의 간격에서 변화한 값과 같다. Y는 X의 절반(올림)과 같다.

### ☐ 대파종 메갈로벨 (행동/대응, 비장패) 소모 2 `[재연 패치]`
- 다른 비장패를 모두 사용한 상태라면, 간격→라이프：1. 이 카드를 게임에서 제거한다.
- 📝 재연: 행동(대응) 소모2

### ☐ 대중력 어트랙트 (행동, 비장패) 소모 5
- 간격→자신 플레어：3  /  ---- /  【재기】이 턴에 당신이 원심을 갖는 카드를 사용하고, 이 카드를 사용하지 않았다.

### ☐ 대산맥 리스펙트 (행동, 비장패) 소모 3
- 원심 / 아래에서 2번까지 선택한다. 같은 것을 여러번 선택해도 된다. / ・당신의 패산을 전부 버림패로 만든다. / ・당신의 버림패에 있는 《전력》이 아닌 카드를 선택해 사용한다. 이 방법으로 사용한 부여가 아닌 카드가 버림패가 된다면, 대신 덮음패로 만든다.
