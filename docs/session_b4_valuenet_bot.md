# B-4 최소 프로토타입: 가치망 봇 vs 챔피언 (2026-07-08)

## 목표
B-1에서 학습한 가치망(val_acc 73~79%)을 실제 봇 의사결정(evaluate 대체)에 넣어,
기존 손짠 평가함수를 넘는지 실측.

## 구현
- `ai/valuenet_bot.py`: ValueNetBot — HeuristicBot과 동일한 1수 시뮬레이션 구조,
  evaluate() 대신 학습된 ValueModel.predict()로 상태 평가.
- 데이터 500판(43033샘플)으로 재학습 → val_acc 79.4% (200판/73%에서 개선).

## 실측 결과
| 대결 | 승률 |
|---|---|
| ValueNetBot vs RandomBot | 66.7% |
| ValueNetBot vs HeuristicBot | **10.0%** |

기존 챔피언(mc48)은커녕 **HeuristicBot에도 크게 열세**. RandomBot조차 압도 못 함
(참고: HeuristicBot은 vs Random 거의 100%).

## 원인 분석 (핵심 발견)

**오프라인 정확도와 탐색 유용성은 다른 것이다.**

1. 극단적 상황(라이프10 vs 1)은 정확히 예측 (98% / 4.5%) — 오프라인 정확도가
   실제로 존재함을 확인.
2. 하지만 **같은 상태에서 서로 다른 후보 수(카드 A vs 카드 B)를 시뮬레이션한
   가치망 점수의 표준편차는 0.0125** — 사실상 노이즈 수준. 즉 "이 수와 저 수
   중 뭐가 나은가"를 구분 못 함.
3. 실제 게임 진행 추적: P0가 명백히 밀리는 상황(라이프8vs10, 오라2vs5,
   evaluate=-24)에서도 가치망 예측은 0.25~0.45 사이를 오가며 뚜렷한 신호를
   못 냄.

**결론**: 오프라인 정확도 73~79%는 "이 스냅샷에서 대략 누가 유리한가"라는
거친 판별(주로 life/aura 총량, 이는 이미 evaluate()의 선형 항으로 해결됨)에는
강하지만, 탐색을 이끌려면 **후보 수들 사이의 미세한 가치 차이**를 배워야 하는데
이는 완전히 다른 난이도의 문제. 4~5만 샘플(약한 봇 1개의 자기대국)로는
이 해상도에 턱없이 부족.

## 이것이 알려주는 것 (AlphaZero와의 진짜 차이)

이 결과는 왜 AlphaZero류가 **수백만~수천만 판**의 자기대국과, 학습된 망 자체로
다음 자기대국을 개선하는 **반복 루프**를 쓰는지를 실측으로 체감시켜준다.
단발성 지도학습(고정 정책의 기보를 한 번 학습)으로는:
- 데이터 다양성 부족 (heuristic 한 봇의 편향된 플레이만 봄)
- 미세 변별력 학습에 필요한 표본 수 부족
- 반복 개선(학습된 망으로 더 나은 자기대국 → 재학습) 없음

세 가지가 모두 빠져 있어 현재 규모로는 손짠 평가를 넘을 수 없다.

## 결정: 실험적 보존, 챔피언 아님

- `ai/valuenet_bot.py`는 코드로 보존 (파이프라인이 실제로 학습→적용까지
  end-to-end 작동함을 보여주는 프로토타입으로서 가치 있음).
- league.py BOTS 레지스트리에는 등록 안 함 (현재 성능으로 오해 방지).
- 챔피언은 계속 MonteCarloBot(K=48).
