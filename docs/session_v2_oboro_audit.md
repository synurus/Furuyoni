# v2 검수 시트: 오보로 (오리진 11장)

> 스팀판 오보로 카드와 대조. 불일치 시 메모.

## 핵심 신규 개념: 설치 (룰북 3-2, 3-3)
- **설치**: 그 자체로는 효과 없음. 규칙 효과로 참조됨
- **핵심 규칙**: 패산 재구성을 수행하면, 그 직전에 설치 카드 1장을 덮음패에서 사용 가능
- 오보로의 여러 카드가 '덮음패에서 사용' 경로를 활용 (닌자걸음, 토비카게, 우로우오 등)
- ⚠️ 재구성 타이밍에 설치 사용 훅 필요 (라이프 지불보다 먼저)

### ☐ 철사 (공격, 통상패) 거리 3-5 2/1 `[재연 패치]`
- 설치 / 덮음패에서 사용했다면, 이 《공격》은 +0/+1 된다.
- 📝 재연: 3-5 2/1, 설치/덮음패 보너스

### ☐ 그림자 마름 (공격, 통상패) 거리 2-3 2/1 `[재연 패치]`
- 설치 / 덮음패에서 사용했다면, 상대를 위축시킨다.
- 📝 재연: 2-3 2/1, 덮음패 시 위축

### ☐ 참격난무 (공격/전력, 통상패) 거리 2-4 3/2
- 【상시】상대가 이 턴 안에 오라로의 대미지를 받았다면, 이 《공격》은 +1/+1이 된다.

### ☐ 닌자걸음 (행동, 통상패) 
- 설치  / 더스트→간격：1  / 이 카드를 덮임패에서 사용했다면, 덮임패에서 설치를 갖는 카드를 1장 사용해도 좋다.

### ☐ 유도 (행동/대응, 통상패) 
- 설치 /  이하에서 하나를 고른다. /  ・간격→상대 오라：1 /  ・상대 오라→상대 플레어：1

### ☐ 분신술 (공격, 통상패) 거리 3-4 2/1 `[재연 패치]`
- 【공격후】손패를 1장 덮음패로 해도 된다. 그렇게 했다면, 공격『적정거리3-4, 1/1』을 행하고, 휘감기를 1회 수행한다.
- 📝 재연: 행동(전력)→공격으로 변경

### ☐ 생체활성 (부여, 통상패) 납 4
- 빈틈 설치  /  【파기시】당신의 사용완료 비장패를 1장 골라, 그것을 미사용으로 되돌린다.

### ☐ 쿠마스케 (공격/전력, 비장패) 거리 3-4 2/2 소모 4
- 【공격후】공격『적정거리3-4、2/2』을 X번 행한다. X는 당신의 덮임패 장수와 같다.

### ☐ 토비카게 (행동/대응, 비장패) 소모 4
- 덮임패에서 《전력》이 아닌 카드를 1장 골라, 그 카드를 사용해도 좋다. 이 때, 이 카드가 대응하는 《공격》이 있다면, 사용된 카드는 그것에 대응하고 있는것으로 취급한다.

### ☐ 우로우오 (부여, 비장패) 소모 2 납 3
- 【전개시】 당신은 버림패를 원하는 숫자만큼 덮은패로 보내도 된다. / 【전개중】 당신이 덮은패에서 사용하는 카드의 화살표는 양방향 화살표(↔)가 된다. / 【전개중/사용됨】 패산을 재구성하기 직전에 설치를 가지는 《공격》이 아닌 카드를 추가로 1장 덮은패에서 사용해도 된다.

### ☐ 미카즈라 (공격, 비장패) 거리 3-7 1/1 소모 0
- 【공격후】더스트→자신 플레어：1  /  ---- /  【재기】당신의 플레어가 0이다.

## ⚠️ 특히 확인할 것
1. **철사/그림자 마름/분신술** 재연 패치 스펙 (특히 분신술: 행동→공격 변경)
2. **쿠마스케**: 덮음패 장수만큼 추가 공격 (X번) — 위력 계산 확인
3. **닌자걸음**: 덮음패에서 사용 시 추가로 설치 카드 사용 — 연쇄 처리
4. **토비카게**(대응): 덮음패의 비전력 카드를 대응으로 사용 — 대응 위임 처리
5. **우로우오**: 3개의 전개중/사용됨 효과가 복잡 — 원문 정확도
6. **생체활성**: 빈틈+설치, 파기시 비장패 재사용
7. 설치 카드를 **일반적으로 손패에서 낼 때는 그냥 공격/행동**이고, 덮음패에서 낼 때만 보너스가 붙는 게 맞나요?
