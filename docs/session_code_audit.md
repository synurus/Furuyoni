# 코드 감사 (2026-07-08)

사용자 질문 "검증이 필요한 부분?"에 대응해 스트레스/표적 검증의 사각지대를 점검.

## 점검한 영역 (전부 정상 확인)

### 1. 종료 페이즈 재기 (immediate:False)
스트레스 테스트가 놓치던 부분. 조건부 재기가 실제로 작동하는지 표적 검증:
- ✅ 뇌라풍신조(라이라): 풍신 4+ 재기, 3이면 안 됨
- ✅ 인과율의 뿌리(메구미): 발아 씨앗 0 재기
- ✅ 윤회의 안개독(치카게): 상대 손패 2+ 재기
- ✅ 미카즈라(오보로): 플레어 0 재기

### 2. 대응(reaction) 카드 무효화/약화
봇이 평소 choose_reaction:None이라 실전 검증이 약했던 부분:
- ✅ 영원한 꽃(토코요): 공격 무효화 (비장 포함, non_special=False)
- ✅ 음무쇄빙(사이네): 오라-1/라이프-1 감소
- ✅ 우아한 타격(토코요): 경지(집중2) 시 통상공격만 무효, 비장은 못 막음
- ✅ 반론(신라): 통상공격 무효화

### 3. non_special 구분
- ✅ 우아한 타격은 비장 공격 무효화 불가 (통상만)
- ✅ 영원한 꽃은 비장 공격도 무효화

### 4. 경지(kyouchi) 조건
- ✅ 집중력 = 2로 정확히 정의됨 (FAQ 507 확인). 검수 시트와 일치.

## 결론
점검한 4개 사각지대 모두 규칙대로 정확히 작동. 검증 내용을 FAQ 테스트 8건으로 고정(총 102건)하여 회귀 보호.

## 감사에서 배운 것
- 표적 검증 셋업 시 방어자 집중력/오라 등 조건 상태를 명시적으로 설정해야 정확한 판정 (초기 우아한타격 오판은 셋업 실수였음).
- 대응 카드는 combat.py의 reacted_attack 버프/cancel 파이프라인으로 일관 처리되어 견고함.
