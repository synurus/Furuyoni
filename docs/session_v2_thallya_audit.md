# v2 검수 시트: 탈리야 (오리진 11장) — v2 마지막 여신

> 스팀판 탈리야 카드와 대조.

## 핵심 신규 개념: 조화결정 / 연소 / 기동 / 변신 (룰북 9장)
- **조화결정**: 신규 토큰 5개. 머신〈machine〉 / 연소됨〈burned〉 / 간격〈gap±1〉 세 위치
- **간격±1 토큰**: '간격-1'(벚꽃결정에 연결, 현재간격 계산서 제외) / '간격+1'(벚꽃결정 간주, 간격 계산에 포함)
- **연소**(9-8): '연소' 표기 카드는 사용 시 추가비용으로 조화결정 1개 머신→연소됨
- **회복**: 연소됨→머신
- **기동**(9-9): 기동전진(머신→간격-1 토큰, 벚꽃결정에 연결) or 기동후퇴(머신→간격+1 토큰). 간격 합 10이면 불가
- **TransForm**(9-3): 추가패의 변신 카드를 머신으로 (Julia's BlackBox)
- **개시 페이즈**: 활성 플레이어 간격±1 조화결정을 연소됨으로 회수
- ⚠️ 조화결정은 벚꽃결정 36개와 별개 계정. 단 간격±1 토큰은 간격 계산에 영향

### ☐ Burning Steam (공격, 통상패) 거리3-5 2/1
- 【공격후】기동을 행한다.

### ☐ Waving Edge (공격, 통상패) 거리1-4 3/1
- 연소  /  【공격후】기본동작을 1회까지 수행한 뒤, 기동을 수행한다.

### ☐ Shield Charge (공격, 통상패) 거리1 3/2
- 연소  /  【상시】이 《공격》의 대미지에 의해 이동하는 벚꽃 결정은, 더스트나 플레어가 아닌 간격으로 움직인다.

### ☐ Steam Cannon (공격, 통상패) 거리3-7 1/1
- 연소 / 전력화: 【상시】 이 《공격》은 거리확대(근1)과 거리확대(원1)을 얻고 +2/+2 된다. / 【공격후】 전력화로 사용하지 않았다면, 당신의 연소상태의 조화결정을 2개 회복한다.

### ☐ Stunt (행동, 통상패) 
- 상대를 위축시킨다。  /  자신 오라→자신 플레어：2

### ☐ Roaring (행동, 통상패) 
- 코스트로,  당신의 머신에 있는 조화결정을 2개 연소완료로 해도 좋다. 그럴 경우, 당신은 집중력을 1 얻고, 상대는 집중력을 1 잃으며, 상대를 위축시킨다。  / 코스트로, 집중력을 2만큼 지불해도 좋다. 그럴 경우, 당신의 연소완료 조화결정을 3개 회복한다.

### ☐ Turbo Switch (행동/대응, 통상패) 
- 연소  /  기동을 행한다.

### ☐ Alpha-Edge (공격, 비장패) 거리1,3,5,7 1/1 소모1
- 【즉재기】당신이 기동으로 간격을 변화시킨다.

### ☐ Omega-Burst (행동/대응, 비장패) 소모4
- 당신의 연소완료 조화결정을 모두 회복한다. /  대응한, 오라로의 대미지가 「-」 혹은 X 이하의 《공격》은 무효화된다. X는 이 카드로 회복한 조화결정의 갯수와 같다.

### ☐ Julia's BlackBox (행동/전력, 비장패) 소모2
- 당신의 머신에 조화결정이 없다면, 당신의 머신은 TransForm하고, 당신의 연소완료 조화결정을 2개 회복한다. 그렇지 않을 경우, 이 카드를 미사용으로 되돌린다.

### ☐ Thallya's Masterpiece (부여, 비장패) 소모2 납3
- 【전개중】당신이 조화결정을 연소시킬 때마다, 머신의 조화결정을 연소됨으로 이동시키는 대신 연소된 조화결정을 머신으로 이동시킨다. / (연소됨 상태의 조화결정이 부족하다면 연소할 수 없다.)

## ⚠️ 특히 확인할 것
1. **준비 시 조화결정 5개가 전부 머신에 놓이는 게 맞나요?** (룰북 9-1)
2. **연소 카드**: Waving Edge/Shield Charge/Steam Cannon/Turbo Switch에 '연소' 표기 → 사용 시 조화결정 1개 자동 연소. 머신에 조화결정 없으면 사용 불가?
3. **기동 전진/후퇴**: 기동전진=간격-1(간격 감소), 기동후퇴=간격+1(간격 증가) 방향 맞나요?
4. **Alpha-Edge 즉재기**: '기동으로 간격을 변화시킨다' 조건 — 이 카드로 기동해서 간격이 바뀌면 재기?
5. **Julia's BlackBox**: 머신에 조화결정 0개면 TransForm+회복2, 아니면 미사용 복귀. TransForm 카드는 추가패에 있나요? (데이터 확인)
6. **Thallya's Masterpiece**: 연소 방향 역전(머신↔연소됨) — 연소됨이 부족하면 연소 불가
7. **Steam Cannon 전력화**: 거리확대 근1+원1 & +2/+2 / 비전력이면 회복2
8. **Roaring/Omega-Burst 코스트**: 조화결정/집중 지불 선택형 — 각 효과 정확도
