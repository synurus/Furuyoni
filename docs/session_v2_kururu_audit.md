# v2 검수 시트: 쿠루루 (오리진 12장)

> 스팀판 쿠루루 카드와 대조. 기교(톱니바퀴칸) 아이콘 조건 확인.

## 핵심 신규 개념: 기교 / 톱니바퀴칸 (룰북 8-2~8-6)
- **톱니바퀴칸**: 일부 카드가 가진 조건부 텍스트. 아이콘(기교)이 완성되면 그 문장이 텍스트로 적용
- **아이콘 5종**: 카드 타입(공격/행동/부여) + 서브타입(전력/대응). {공공}=공격 2개, {행행부}=행동2+부여1 등
- **완성 조건 (8-3)**: 버림패 + 부여패 + 사용된 비장패에, 해당 타입/서브타입 카드가 아이콘 수 이상 존재
- **듀플리기어**(추가패 3장): 인더스트리아에 봉인된 카드의 복제. 봉인 없으면 사용 불가
- ⚠️ 사용 이력을 타입별로 카운트하는 시스템 필요 (지금 엔진에 없음)

### ☐ 엘레키텔 (행동, 통상패) 
- ---- /  <행행행대대>상대의 라이프에 1 대미지를 준다.

### ☐ 액셀러~ (행동, 통상패) 
- ---- /  <행행부> 당신의 손패에서 《전력》카드를 1장 고르고, 그 카드를 사용해도 좋다. /  (페이즈는 종료되지 않는다.)

### ☐ 쿠루룽~ (행동/대응, 통상패) 
- 【상시】이 카드는 대응으로만 사용한다. /  이하에서 2개까지 고르고, 임의의 순서로 행한다.  /  (같은 것을 2번 고를 수 없다.) /  ・카드를 1장 뽑는다. /  ・덮임패 1장을 패산 밑에 둔다. /  ・상대는 손패를 1장 버림패로 한다.

### ☐ 토네~이도 (행동/전력, 통상패)  `[재연]`
- {공공} 오라에 5 데미지 / {행행} 플레어에 1 데미지 / {부부} 라이프에 1 데미지
- 📝 재연: 기계장치 3단

### ☐ 리게이너 (행동/전력, 통상패) 
- ---- /  <부대> 버림패, 덮은패, 비장패 중에서 미사용 상태도 《전력》도 아닌 다른 여신의 카드를 1장 선택할 수 있다. / 당신은 그 카드를 비용을 지불하지 않고 사용한다. 이 때, 모든 적정거리 수치 / 오라 대미지 / 라이프 대미지 / 봉납치 중 하나를 선택하여 그 수치를 1만큼 증가하거나 감소시킬 수 있다. /  ---- / 【상시】이 카드는 덮임패에 있어도 당신의 손패에 있는 것처럼 통상 방법으로 사용할 수 있다.

### ☐ 모듀르~ (부여, 통상패) 납3
- 【전개중】당신이 《행동》카드를 사용했을 때, 그 해결 후에 기본 동작을 1회 행해도 좋다.

### ☐ 리플렉터 (부여, 통상패) 납0
- ---- /  <공대> 【전개시】이 카드 위에 벚꽃 결정을 4개 더스트로부터 올린다. /  ---- /  【전개중】매 턴 상대의 2번째 《공격》은 무효화된다.

### ☐ 드레~인 데빌 (행동/대응, 비장패) 소모3 `[재연]`
- 상대 오라→자신 오라：1  /  【사용완료】당신의 사용완료 비장패가 미사용으로 되돌아갈때, 이 카드를 소비를 지불하지 않고 사용해도 좋다.
- 📝 재연: 소모값 3으로 변경 (효과 유지)

### ☐ 빅 골~렘 (행동, 비장패) 소모4
- ---- /  <대전전> 【사용완료】당신의 종료 페이즈에 상대의 라이프에 1 대미지를 주어도 좋다. 그럴 경우, 패산을 재구성한다. /  ---- /  【사용완료】당신이 《전력》카드를 사용했을 때, 그 해결 후에 기본동작을 1번 해도 좋다.

### ☐ 인더스트리아 (행동, 비장패) 소모1
- 이 카드에 카드가 봉인되어 있지 않다면, 당신의 손패 또는 버림패에서 《부여》가 아닌 카드 한 장을 골라, 그 카드를 이 카드 밑에 앞면으로 봉인해도 좋다. /  당신의 추가패에서 「듀~플리기어」를 패산의 밑에 1장 둔다(최대 합계 3장).  /  ---- /  【즉재기】당신이 패산을 재구성한다(재구성 후에 미사용으로 되돌린다).

### ☐ 신섭장치:쿠루루식 (행동, 비장패) 소모3
- ---- /  <공공행행행부부> 상대의 비장패를 보고, 그 중 1장을 골라, 그것을 사용완료로 해도 좋다. /  ---- /  상대의 사용완료 비장패를 1장 골라도 좋다. 그 카드를 소비를 지불하지 않고 사용한다(《전력》카드여도 좋다). 그 후, 이 카드를 제외한다.
