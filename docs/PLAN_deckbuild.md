# 2여신 덱 구축 계획

## 목표
단일 여신 프리셋 → 2여신 선택 + 안전구축(통상7/비장3) + 무다시(첫 손패 교환).
v2에서 미룬 "다른 여신 의존 효과" 활성화.

## 단계
1. **PlayerState 다여신화**: `name`(단일) → `megamis`(2개) 병행 유지. 여신별 초기화(씨앗/계략/조화결정)를 리스트 순회로.
2. **안전구축 API**: `build_two_megami_deck(m_a, m_b, picks)` — 20장 풀(각 여신 통상7+비장3~4)에서 통상7/비장3 선택. 봇 정책: 기본 프리셋(각 여신 대표 카드) 또는 에이전트 위임.
3. **new_game_2v2()**: 2여신 게임 생성. 기존 new_game은 내부적으로 이걸 호출(단일=같은 여신 2번? 아니면 유지).
4. **무다시**: 4-1-1 과정 5 (손패 일부를 패산 밑에 넣고 같은 수 뽑기). 에이전트 훅 choose_mulligan.
5. **다른 여신 의존 효과 활성화**: 초극, 라이라 대전 게이지, 껍질치기, Dual Action 버림패 공격, 오보로 대응 위임 등 — 2여신 덱에선 다른 여신 카드가 존재하므로 자연히 활성화. 개별 검증.
6. **91페어링 스트레스**: 14여신 C(14,2)=91 조합 전부 미러/교차.
7. **AI 대응**: 평가함수/휴리스틱이 2여신 상태공간 처리 (기존 evaluate 재사용 가능성 확인).

## 스코프 판단
- 어나더 여신 제외 유지 (오리진만).
- 안전구축의 "카드 준비" 물리 과정은 추상화: 각 여신 카드 풀에서 선택.
- 무다시는 봇 기본 skip 가능(선택 과정), 에이전트 훅만 제공.

## 검증 원칙
- 기존 81 FAQ 테스트 전부 유지 (단일 여신 회귀).
- 2여신 신규 테스트 추가.
- 벚꽃결정 보존식은 2여신에서도 불변 (여신별 신규 토큰은 각자 계정).
