## 여신별 신규 메커니즘 조사 및 구현 순서

난이도(신규 시스템 수) 오름차순. 각 여신은 "데이터 검수 → effects 구조화 → 엔진 확장 → FAQ 테스트 → 미러전 스트레스"의 미니 사이클로 진행.

| 순서 | 여신 | 신규 시스템 | 엔진 영향 | 비고 |
|---|---|---|---|---|
| ✅ | **하가네** | 원심(턴 시작 간격 대비 변화 조건), 연성(재연 신규) | 낮음 — `turn_start_distance` 이미 존재 | 원심 키워드 정의 확인 필요 |
| ✅ | **코르누** | 동결(상대 오라 결정을 동결 상태로) | 중 — 오라에 상태 있는 결정 개념 | 동결 해제 규칙 확인 |
| ✅ | **오보로** | 설치(덮음패에서 카드 사용) | 중 — 덮음패 사용 경로 신설 | 기가스케 원본 미해결 |
| ✅ | **라이라** | 풍신/뇌신 게이지(전진·후퇴/데미지 훅), 폭풍의 힘 소환 | 중 | 질풍제천의 원본 미해결 |
| ✅ | **치카게** | 독주머니, 상대 패산에 독 카드 삽입 | 중 — 카드 소유권 교차 | 독 4장 별도 카드군 |
| ✅ | **유키히** | 우산 상태(카드 스펙 이중화) | 중 — 데이터에 opened 필드 확보됨 | |
| ✅ | **메구미** | 씨앗 결정, 토양 | **높음 — 벚꽃결정 36개 밖의 신규 토큰 → 보존식 확장** | |
| ✅ | **신라** | 계략(주장/반증), 봉인, 상대 패산 조작 | 높음 | 반증 실패 시 초조 (기구현 재사용) |
| ✅ | **쿠루루** | 기계장치 조건({공공}=이 턴 공격 2장 등), 카드 복제 | 높음 — 사용 이력을 타입별 카운트로 확장 | 레일 건 원본 미해결 |
| ✅ | **탈리야** | 조화 결정(신규 토큰), 변신(기계), 기동 | **최고 — 보존식 확장 + 상태 기계** | Quick Change 원본 미해결 |

## ⚠️ 사용자 확인 필요 (패치노트 ↔ 데이터 매칭 실패 4건)

재연 패치노트에 있으나 기존 데이터에서 원본 카드를 찾지 못한 카드들.
스팀판에서 해당 여신의 카드 목록을 보시고 **어떤 카드가 빠지고 이 카드가 들어왔는지** 알려주세요:

1. **기가스케** (오보로, 16플레어) — 데이터의 「쿠마스케」 개명·리워크로 추정. 맞나요?
2. **레일 건** (쿠루루, 공격 2-6 1/2) — 쿠루루 통상패엔 공격이 없었는데, 어떤 카드와 교체됐나요?
3. **Quick Change** (탈리야) — 패치노트가 "부여→행동 변경"이라 기존에도 있던 카드 같은데, 데이터의 어느 카드인가요? (Turbo Switch?)
4. **질풍제천의** (라이라, 행동 2플레어) — 어떤 비장패의 개명/교체인가요? (천뢰소환진? 풍마초래공?)

## 검수 방식

v1 검수에서 효과가 컸으니 동일하게: 각 여신 구현 직전에 그 여신 11장의
검수 시트(스팀판 대조)를 뽑아 확인받고 시작. 미해결 4건도 그때 함께 해소.
