# v2 검수 시트: 유키히 (오리진 11장)

> 스팀판 유키히 카드와 대조. 우산 카드는 [접힘]/[폄] 양쪽 스펙 모두 확인.

## 핵심 신규 개념: 우산 (룰북 4장)
- **우산 개폐 상태**: 유키히 플레이어의 공개 정보. 시작 시 **접힘**
- **우산 카드**: 텍스트·적정거리·오라뎀·라이프뎀이 보유자의 현재 우산 상태에 따라 전환
- **우산의 개폐**: 상태를 반대로 뒤집는 행위 (여러 카드가 수행)
- 참조 시점 기준: 카드를 해결하는 순간의 우산 상태를 따름

- [접힘] (없음)

### ☐ 숨긴 불꽃 / 손뼉치기 (공격, 통상패) [접]거리5-6 [폄]거리0-2 [접]1/1 [폄]1/1
- [접힘] 【공격후】이 카드를 손패로 되돌리고, 우산의 개폐를 행한다.

### ☐ 떨쳐내기 / 끌어당기기 (공격, 통상패) [접]거리2-5 [폄]거리0-2 [접]1/1 [폄]1/1

### ☐ 휘두르기 / 푹 찌르기 (공격/전력, 통상패) [접]거리4-6 [폄]거리0-2 [접]5/- [폄]-/2

### ☐ 뒷걸음질 / 파고들기 (행동/대응, 통상패)

## ⚠️ 특히 확인할 것
1. **흩날리는 눈꽃 즉재기**: '우산의 개폐를 행한다'가 재기 조건인데, 이 텍스트가 [폄] 쪽에만 연결돼 있어요.
   → 개폐할 때마다 재기인가요, 아니면 **펴짐 상태가 될 때만** 재기인가요? (텍스트-아이콘 연결 규칙상 후자로 추정)
2. **우산 돌리기 상시**: 우산 개폐 시 손패에서 이 카드를 '공개'하면 더스트→오라 1 — 개폐 1회당 1번씩인가요?
3. **거리확대(근1)**: 질척이는 속내의 근거리 확대 — 적정거리 최소값이 1 줄어드는 게 맞나요? (원1의 반대)
4. **인연 맺기 화살표 반전**: 파기시 효과의 방향은 '파기 시점'의 우산 상태를 따르나요?
5. **숨긴 불꽃**: 공격후 '손패로 되돌리고 개폐' — 양쪽 상태 공통 텍스트인가요?
