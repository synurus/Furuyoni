# CLI 플레이 가이드

사람이 직접 후루요니를 플레이하는 방법. (Windows: `python cli\play.py`)

## 빠른 시작

```bash
# 단일 여신 (기존 방식): 유리나(나) vs 토코요(봇)
python cli/play.py yurina tokoyo

# 2여신 덱 모드: 대화형 덱 구축 (쌍장요란 → 안전구축 → 무다시)
python cli/play.py --two

# 강한 봇과 대결 (기본 aggressive → heuristic/mc24/mc48)
python cli/play.py --two --bot mc48
```

## 2여신 모드 흐름 (--two)

1. **쌍장요란**: 14여신 목록에서 내 여신 2명을 번호로 선택 (예: `1 9`)
2. **안전구축**: 두 여신의 통상 14장 풀에서 7장, 비장 8장 풀에서 3장 선택
   - 번호를 공백으로 구분해 입력 (예: `1 2 4 6 8 10 12`)
   - **`d` 입력 시 스마트 자동 추천** (AI 덱 정책이 골라줌)
3. 상대(봇) 여신은 무작위 2명 + 자동 덱
4. **무다시**: 첫 손패 중 교환할 카드 번호 입력 (없으면 엔터)
5. 게임 시작!

## 플레이 중 명령

| 입력 | 동작 |
|---|---|
| 숫자 | 해당 행동 선택 |
| `r` | AI 훈수 (휴리스틱 추천 수) |
| `q` | 게임 종료 |

## 옵션

| 옵션 | 설명 |
|---|---|
| `--two` | 2여신 덱 모드 (대화형 덱 구축) |
| `--bot NAME` | 상대 봇: aggressive(기본)/heuristic/mc24/mc48 |
| `--hotseat` | 사람 vs 사람 (2여신 모드면 양쪽 다 무다시) |
| `--seed N` | 시드 고정 (재현용) |
| `--first 0|1` | 선공 지정 |

## 화면 읽는 법

```
턴 3 | 활성 P0 | 간격 4 (유효 3) | 더스트 5
▶P0 raira+thallya (나): 라이프10 오라3 플레어2 집중1 달인간격2
   자원: 풍신2/뇌신1 / 머신조화4/연소1
   패산2 버림3 덮음0 | 부여: 압도[2]
   ...
```
- **유효 간격**: 까치발/조화결정 간격±1 등이 반영된 실제 판정 간격
- **자원**: 여신별 신규 자원 (게이지/조화결정/씨앗/동결/독주머니/계략/우산)
- 부여 `[2+씨1]`: 벚꽃결정 2 + 씨앗 1 (메구미)
